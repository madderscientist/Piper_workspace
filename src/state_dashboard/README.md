# 四臂 Dashboard

浅色、全宽的四臂配置与调试工作台。每臂一行，显示设备状态、六关节反馈、末端配置、MIT 调试滑块和末端位姿。
**Dashboard 是纯 ROS 客户端，不直接打开 CAN。**

## 1. 启动

先按 [工作空间 README](../../README.md#环境与构建) 完成构建；同一 `ROS_DOMAIN_ID` 下分别启动驱动与 Dashboard：

```bash
# 终端 1：启动四臂驱动
ros2 launch piper_x_driver four_arms.launch.py

# 终端 2：启动 Dashboard（默认监听 http://127.0.0.1:8089/）
ros2 run state_dashboard state_dashboard --port 8089
```

通过 SSH 远程访问时将 `8089` 端口转发到本地：`ssh -N -L 8089:127.0.0.1:8089 user@robot-host`。
若使用自定义配置文件，驱动和 Dashboard 需指定同一份 `--config /absolute/path/arms.yaml`。

## 2. 功能与操作

- **状态与使能**：四臂独立控制；使能状态来自实际电机反馈（`0x261`～`0x266`），状态未知或部分使能时优先提供失能。
- **顶部四臂示教控制栏**：实时显示 `/bilateral_teaching/state` 的模式、阶段与对齐误差，支持一键切换 `master_slave` / `bilateral`、启动和停止示教。
- **分层级视图（四臂总览 + 单臂放大 3D 工作台）**：
  - **第一层（四臂总览）**：专注四臂只读遥测（设备状态、六轴反馈与趋势、末端六维力与受载外力矩、末端位姿与各层实时频率），保持首屏清爽高密度。
  - **第二层（单臂放大 3D 工作台 Studio）**：点击任意行的 **“⤢ 展开控制 · 3D”** 打开：
    - **左侧 3D STL 视口与六维力监控**：支持鼠标旋转、缩放、平移、四向预设视角、线框/实体切换、半透明目标姿态虚影（Ghost Mesh）、笛卡尔目标坐标轴预览，以及实时末端三维力矢量叠加显示与六轴力/力矩卡片。
    - **顶部模式切换栏**：支持切换 7 种驱动模式（`mit` / `joint` / `point` / `linear` / `drag` / `hold` / `standby`）。
    - **MIT 阻抗控制 · 夹爪**：提供“自由移动（零重力）”与“跟踪滑条（锁定位置）”切换、六轴 MIT 参数与目标滑条表格，以及末端夹爪开度/力度指令（`command/gripper`）。
    - **关节 MoveJ · 笛卡尔 MoveP/L**：下发带实测对比与 `Δ` 差值提示的六轴关节目标（`command/joints`）和六自由度笛卡尔目标（`command/cartesian`）。
    - **关节力矩拆解**：实时展示六轴实测角、受载外力矩、惯性力矩、重力补偿、摩擦补偿与下发前馈。
    - **负载配置 · 标零 · 诊断**：集成末端类型切换、重力补偿系数滑条、内联闭合零位标定、逐轴限位/通信诊断、各层频率链路与 11 路 CAN 报文时效。

### 末端闭合零位标定

1. 退出 MIT/示教，确认六关节与末端全部失能且反馈新鲜。
2. 确认末端无夹物并处于物理完全闭合位置（软件不会自动闭合末端）。
3. 在单臂工作台切换至 **“负载配置 · 标零 · 诊断”** 标签页，勾选确认复选框后点击 **“写入此臂闭合零位”**。
4. 驱动调用 `calibrate_gripper(timeout=1.0)` 并在 `0.5 s` 内校验新鲜失能零位回读（`0..0.1 mm`）；标定不会自动使能电机。

详细 ROS 消息与服务定义见 [驱动与 ROS 接口文档](../piper_x_driver/README.md#6-对外暴露的-ros-2-接口与完整字段契约)。
